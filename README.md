# DeepNN_vs_Autoencoder_kmeans
This application provide you three built-in machine learning methods.
Models are trained using imdb review dataset. You may check the dataset on https://www.kaggle.com/datasets/utathya/imdb-review-dataset.
This application is intended for experimental use only, not for training a classification model.
This is deployed on https://dnvack.streamlit.app/.
